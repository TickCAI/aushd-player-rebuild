## 3. M1.5：分类浏览页（Tab + Facet）

| 文件 | 改动 | 为什么 |
|---|---|---|
| `lib/core/emby/models/emby_item.dart` | 新增 `List<String> productionLocations`（构造/copyWith/fromJson/`ProductionLocations`） | Emby/Jellyfin 的 `ProductionLocations` 是地区维度的权威字段 |
| `lib/data/catalog_api.dart` | `cardFields` 加 `Studios,ProductionLocations`；`query()` 加 `studios`/`productionLocations` 参数 | 让服务端能按平台/地区过滤；Jellyfin 忽略未知参数时由客户端兜底过滤 |
| `lib/l10n/content_zh.dart` | 新增 `ContentZh.region(raw)` + 地区归一化表 | 把 `China/Japan/US/…` 归一到中文桶，Facet 才能聚合成「中国/日本/美国」 |
| `lib/ui/widgets/side_panel.dart` | 新增 `showMultiSelectSidePanel<T>` | 同维度多选 OR 的交互底座（清除/确定/勾选） |
| `lib/ui/pages/library_page.dart` | 新增 `_BrowseTab`(featured/topRated/recent/upcoming) 与 `_Facet`(studio/year/region)；Tab 行 + Facet 行；`_filterLocally` 客户端过滤；`_fetched` 原始分页计数避免本地过滤后重复拉取；upcoming 仅 seerr 配置时显示 | 扩展现有浏览页，复用 query/grid/FocusZone，不新开页面；保持与现有 sort/genre/watched/view 共存 |

### 交互语义

- 同维度多选 = OR（选了日本+韩国 → 命中任一）。
- 跨维度 = AND（平台∩年份∩地区）。
- Tab 决定默认排序：高分→rating、最近→added、精选/即将上映→released。
- 即将上映依赖 Seerr（未配置时隐藏该 Tab），按 `premiereDate > now` 过滤。

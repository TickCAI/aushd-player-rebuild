## 背景

真机验收阶段1~3（配置热更 / OpenList 挂载 / 弹幕）后，用户反馈五个问题，本批次集中修复：

1. 首页「我的媒体库」行不见了。
2. 首页「观看记录」（续看区）不见了。
3. 首页发现行卡片显示「求片」，应为「待播」，且命中媒体库的项应跳影片详情页（与发现中心逻辑一致）。
4. OpenList / WebDAV 添加存储源应有协议 / 网盘下拉菜单，用地址 + 用户名 + 密码填写。
5. 弹幕源完全点不了（「暂无弹幕源——随配置更新下发」，开关禁用），应允许用户自行填入三方弹幕源地址。

## 改动明细

### 1 & 2：恢复「我的媒体库」与「观看记录」行（首页加载重试）

- 文件：`lib/ui/pages/home_page.dart`
- 根因：`_load()` 用 `_data.putIfAbsent` 缓存加载 future；Emby 的 `/Views`、`/Resume` 在冷启动时若超时（代理 504），失败的 future 被**永久缓存**，整会话不再重试，空结果被 `if (items.isEmpty) return SizedBox.shrink()` 隐藏，看起来像「行消失了」。
- 修复：
  - 新增 `_loadFailures = <_Row, int>{}` 与 `_maxLoadRetries = 3`。
  - `_load()` 成功时清除失败计数；catch 时计入失败次数，未达上限则 `Future.delayed(2 * tries 秒)` 后移除失败 future、`setState` 重建、`_load(row)` 直接重试（注意 `_pump()` 只加载 newly-allowed 行，故必须直接调 `_load`）。
  - `refresh()` 时清空 `_loadFailures`。
- 效果：代理从 504 恢复后，媒体库 / 续看行会在数秒内自动出现，不再需要重启 APP。

### 3：首页发现行改「待播」标签 + 命中库跳详情

- 文件：`lib/ui/widgets/mixed_cards.dart`、`lib/ui/pages/home_page.dart`
- `mixedCard` / `_mixedCard` 加 `discovery` 布尔参数；发现行为 `true`。
- 新增 `discoveryStatus(L10n, {required bool inList})`：
  - 已在待播 → 「待播中」/ check_circle / textMuted
  - 未拥有 → 「待播」/ bookmark_border / Zc.request
- SeerrMedia 发现卡片用上述状态覆盖 `RequestPosterCard` / `RequestLandscapeCard` / `SpotlightCard` 的 pill（三种卡片样式均支持 `statusLabel/statusColor` 覆盖）。
- `EmbyItem`（命中库）分支不变，仍走 `openItem` 进 Emby 详情页；SeerrMedia 走 `openRequest` 进 Seerr 详情页。即首页发现行与发现中心的「待播 + 点击进详情」逻辑完全一致。
- `_discoveryRow` 已用 `recommender.resolve()` 把命中的项换成 EmbyItem，故命中库项天然进 Emby 详情。

### 4：存储源协议下拉 + 统一凭据输入

- 文件：`lib/data/mount/mount_service.dart`、`lib/data/mount/openlist_vfs.dart`、`lib/data/mount/ftp_vfs.dart`（新增）、`lib/ui/pages/storage_sources_page.dart`
- `MountKind` 扩为 `{openlist, webdav, ftp}`；新增 `ProtocolPreset` 预设表：
  - OpenList / AList、WebDAV、FTP / FTPS
  - 阿里云盘 / 百度网盘 / 115 / 夸克 / OneDrive / Google Drive / SMB（均为 OpenList 网关预设，提示「需先部署 OpenList」）
- 添加流程改为：`showSidePanel<ProtocolPreset>` 选协议 → 名称 → 地址 → 用户名 → 密码。
- OpenList 若填了用户名，自动 `OpenListVfs.authenticate()`（POST `/api/auth/login`）换取 bearer token，用户无需找原始 token；失败则留空（公开实例仍可用）。
- 新增 `FtpVfs`：纯 Dart Socket 实现，支持 USER/PASS、被动模式（EPSV/PASV）、MLSD 优先 + LIST 回退目录列举、生成内嵌凭据的 `ftp://user:pass@host/path` 直链交给 mpv。诚实边界：不支持 FTPS（AUTH TLS）与主动模式；Android Media3 无法直接播 ftp://，桌面 mpv 为支持目标。
- 三种后端均用「地址 + 用户名 + 密码」统一凭据形状（OpenList 额外自动换 token）。

### 5：用户自填弹幕源

- 文件：`lib/data/danmaku/danmaku_service.dart`、`lib/ui/pages/settings_page.dart`
- `DanmakuService` 新增 `_userSources`（本地持久化），与签名配置下发的 `_configProviders` 合并成有效 provider 列表。
  - `addUserSource({name, url, requiresTmdb})`：新增源并自动启用、选为当前源。
  - `removeUserSource(id)` / `isUserSource(id)`。
  - `restorePrefs()` 还原用户源；`_persist()` 一并写入 `{enabled, provider, sources}`。
  - 配置刷新只替换 config 源，**不删用户源**。
- 设置页弹幕分区新增「添加弹幕源」「管理我的弹幕源」两行：
  - 添加：两次输入框填名称 + URL 模板，URL 必须以 http 开头，含 `{tmdb}/{douban}/{title}/{season}/{episode}` 占位符。
  - 管理：侧滑列用户源，选择即删除。
- 无配置签名密钥的部署也能用弹幕（不再依赖远端下发）。

## 诚实边界

- 云端 CI 不接真实 Emby / OpenList / FTP / 弹幕源，只验证编译与单测；真机需自配服务验收。
- FTP 不支持 FTPS / 主动模式；Android 无法直播 ftp://。
- 弹幕源模板占位符由提供方约定，错误模板会返回空弹幕（不崩溃）。
- 首页行重试最多 3 次，彻底不可达的源仍会隐藏该行（避免无限重试）。

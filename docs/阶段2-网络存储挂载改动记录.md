# 阶段2：网络存储挂载（OpenList 网关 + WebDAV）改动记录

> 属于《下一阶段开发方案-热更弹幕账号挂载.md》的阶段2。目标：让用户把 NAS / 网盘里的媒体像媒体库一样浏览并直接播放，无需 Emby 刮削入库。

## 一、背景与边界

- 决策：**以 OpenList 为统一网关**。OpenList（AList 同类）把 WebDAV / SMB / 各家网盘统一暴露成一个 HTTP 服务，客户端只对接它一家，SMB 不再需要客户端直连（Dart 生态无成熟 SMB 库，原生桥接成本高）。
- 补充通道：`WebDavVfs` 直连标准 WebDAV 共享（PROPFIND），给不想部署 OpenList 的用户。
- 凭据只存本地（LocalStore），后续阶段4 的云同步会明确排除这些字段。
- 无挂载源时，设置页正常显示空列表；本阶段不向首页注入任何行，纯本地功能，不依赖分发服务。

## 二、数据层（`lib/data/mount/`，新建）

### `virtual_file_system.dart`
- `VirtualFile`：name / path（规范化后端绝对路径）/ isDir / size / modified / thumbUrl。
- `VirtualFileSystem` 抽象：`list(path)` / `resolvePlayableUrl(path)` / `check()` / `id` / `displayName`。
- `VfsPath` 工具：`normalize`（反斜杠→`/`、折叠重复斜杠、去 `.`、弹 `..` 且不越根、恒 `/` 开头无尾斜杠）、`join`、`basename`、`dirname`、`encode`（逐段百分号编码保留 `/`）。

### `openlist_vfs.dart`
- 列目录：`POST <base>/api/fs/list`，body `{path,password,page,per_page,refresh}`，可选 `Authorization: Bearer <token>`。
- 解析容错：兼容 `is_dir`/`isDir`、显式 `path` 或与父目录 join、`code!=200` 抛错；目录优先 + 名称排序。
- 直链：`GET <base>/d/<编码路径>`，直接交给播放器内核。

### `webdav_vfs.dart`
- `PROPFIND`（Depth:1，Basic auth）列目录；零依赖正则解析 multistatus（href / collection / getcontentlength / getlastmodified），跳过集合自身。
- 直链 = 文件自身 URL；配置了账号时把凭据嵌入 URL（`https://user:pass@host/...`），让 mpv 原生层能鉴权。

### `mount_service.dart`
- `MountDefinition`（id/kind/name/baseUrl/token/username/password）+ JSON 序列化 + `toVfs()`。
- `MountService extends ChangeNotifier`：持久化在 LocalStore 键 `aushd.mounts.v1`；`load/add/remove/byId/vfsFor`；增删即 `notifyListeners()`。同 id 替换不重复。

## 三、播放链路（`lib/ui/core/playback_launcher.dart`）

- 新增 `playDirectUrl(context, url, {title})`：复用久经考验的 `LiveSession`，喂一个带 URL 的 `LiveSource`——`_play()` 检测到 url 非空即 `_player.load(Uri.parse(url))`，完全绕过 Xtream 账号逻辑。锁/Trailer 停播/失败提示/RenderGuard 收尾与其它播放路径一致。
- Android 走 Media3、桌面走 mpv，由 `createPlayer` 自动分派，无需分支代码。

## 四、UI

- `storage_sources_page.dart`（设置 → 服务 → 存储源）：添加（选后端类型 → 名称/地址/令牌或账号，逐文本框向导）、测试连接、编辑、删除（确认弹窗）、打开浏览。
- `storage_browser_page.dart`：网盘文件网格浏览；目录进入、`..`/返回键回上级（BackHandler）、文件点击解析直链后 `playDirectUrl`；错误态带重试；视频扩展名显示播放图标。
- 设置页 services 段新增"存储源"入口行。

## 七、诚实边界

- OpenList API 字段以方案契约 + 常见实现为准做了容错，但**未对真实 OpenList 实例联调**（本机无服务、CI 不联网测试）；真机验收时若个别字段不符，只需调整 `openlist_vfs.dart` 解析。
- WebDAV 解析是轻量正则实现，覆盖常见 DAV 服务器；个别服务器用非标准属性命名时可能读不到 size/modified（不影响浏览与播放）。
- 凭据嵌入 URL 是 WebDAV 直连的现实妥协（mpv 无 header 注入接口）；日志里可能带 userinfo，排障时注意。
- 网盘文件没有 Emby 元数据，本阶段只做"能浏览能播"；海报/简介补全（按文件名匹配 TMDB）留作后续增强。

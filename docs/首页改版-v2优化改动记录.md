# 首页改版 v2 优化改动记录（2026-11-21）

## 0. 一句话结论

针对"智能片单很烂 / 片源太少 / 平台太多"三条反馈，做了三件事：六个片单改成**六个独立意图 + 各自权重**、智能片单接 **Seerr/TMDB 自适应补位**（未配置则退回本地）、把错标的"平台"改成**"出品方"并收敛到 top12 + 搜索**。全部改动走 GitHub 云端 CI 验证（本机无 flutter/dart）。

## 1. 三条反馈 → 根因 → 对策

| 反馈 | 根因（代码事实） | 对策 |
| --- | --- | --- |
| 智能片单很烂 | 六个 spec 除 nextUp 外都走同一 `SmartKind.emby` 分支，是同一池子的不同阈值；高分经典/冷门佳作/本周推荐高度重叠。`itemScore` 固定权重，"经典"因新鲜度衰减反而排低 | 六个 spec 改成独立意图，各自 `wRating/wTaste/wFresh/wJitter`；classics 不吃新鲜度亏、fresh 重新鲜、gems 重抖动、picks 重口味 |
| 片源太少 | 首页所有行来自本地 Emby；`SmartKind.seerr/hybrid` 在 resolver 里是死代码直接返回空，从不读 TMDB/Seerr | `SmartListResolver` 加可注入 `SmartTopUp`；`resolveMixed` 本地不足时用 Seerr/TMDB discover 补位；`mixedCard` 本就支持 SeerrMedia（未入库显示"请求"），无需改卡片 |
| 平台太多太乱 | `library_page.dart` 的"平台"facet 实际绑定 `studios` = 制片公司（A24/华纳），名实错位；且全部平铺无收敛 | 改名"出品方"；按当前库出现频次排序；picker 只显示 top12，长尾靠搜索；底部"显示全部 N 项"兜底 |

## 2. 六个片单的独立意图

| id | 标题 | 意图 | 权重/规则 |
| --- | --- | --- | --- |
| this-week | 本周更新 | 最近入库未看 | 14 天窗、`IsUnplayed`、按 DateCreated 排、不打分 |
| classics | 高分经典 | 高分剧集 | Series only、≥8、无 maxYear、`wFresh=0`、`wRating=0.60` |
| fresh | 新片速递 | 近期追更 | Series、180 天窗、`IsUnplayed`、`wFresh=0.50` |
| gems | 冷门佳作 | 中高分冷门 | 6.5–7.8、未看、`wJitter=0.30`、`wFresh=0` |
| one-ep | 一集入坑 | 每剧下一集 | `nextUp`，按 seriesId 去重 |
| picks | 本周推荐 | 口味匹配 | ≥7、未看、`wTaste=0.50`、带 People 字段 |

**注意**：id 全部保持不变，因此 l10n key、首页行映射、More 浏览页 `byId` 反查都不用改。打分仍是 `wRating*norm(rating) + wTaste*tasteMatch + wFresh*freshness + wJitter*stableJitter`，只是权重从固定变成逐片单配置（默认值保持 0.45/0.30/0.15/0.10 向后兼容）。

## 3. Seerr/TMDB 自适应补位

- `SmartTopUp` = `Future<List<Object>> Function(SmartSpec spec, int missing)`，可注入。
- `SmartListResolver.resolveMixed()`：先本地候选，不足时调 topUp 补位；按 EmbyItem.id 去重；topUp 抛异常时退化成本地（绝不空行）；低于 `minItems` 整行隐藏。
- `home_page.dart` 的 `_smartTopUp(s)`：**仅当 Seerr 或 TMDB 已配置**才返回回调——用户没装 Seerr 也能正常工作（纯本地），装了才补位。
  - 按 spec 类型选 tv/movie；classics/picks 用 `vote_average.desc`（带 vote_count 下限）、fresh/this-week 用 `release_date.desc`、gems 用 `popularity.asc`。
  - `recommender.discover` → `recommender.resolve` 把 TMDB 命中映射回本地 EmbyItem，未匹配保留 SeerrMedia。
- 缓存 key 加 `|local|mixed` 区分，两种模式互不污染；`libraryChanged` 时 `invalidate()`。

## 4. 平台 → 出品方

- `library_page.dart`：`_studioOptions()` 按频次降序；facet 按钮与 picker 标题从"平台"改成"出品方"；picker 传 `initialLimit=12` + `searchHint='搜索出品方'`。
- `side_panel.dart`：`showMultiSelectSidePanel` / `_MultiSelectPanel` 加 `searchHint`、`initialLimit`；带搜索框（实时过滤）、长尾截断、底部"显示全部 N 项"。搜索/全显是本次唯一的新 UI 交互。

## 6. 诚实边界

- 云端 runner **不连真实 Emby/Seerr/TMDB**，所以"补位后片单是否真的更丰富""口味匹配是否真的准"无法在云端证明，需真机接真实数据源看。
- `mixedCard` 对 SeerrMedia 的"请求"按钮是已有能力，本次只是让智能片单能走到这条路。
- 平台收敛只改了 facet 的展示与排序，不改服务端查询语义（studio 仍是本地过滤维度）。

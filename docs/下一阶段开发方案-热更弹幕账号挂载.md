## 1. 现状侦察结论（实施前的真实底座）

### 1.1 客户端

- `pubspec.yaml`：`sdk: ^3.13.0`；依赖 `http`, `shared_preferences`, `path_provider`, `crypto`, `uuid`, `web_socket_channel`, `ffi`, `win32` 等。**无 SMB/WebDAV/Danmaku 库**，需新增或自研。
- 播放器内核：**libmpv（FFI）**，`lib/playback/mpv/` 下有 `libmpv.dart`、`mpv_backend.dart`、`mpv_player.dart`、`mpv_options.dart`；已有字幕链路（`subtitle_style.dart` / `track_policy.dart` / `mpv_conf.dart`）。
- 会话/登录：
  - `lib/app/hub_link.dart`：兑换码绑定 + features 下发（requests/together/profiles/redownload）。
  - `lib/core/emby/janus_service.dart`（经 `app_services.dart` 引用）：`isAuthenticated` / `restoreSession()` / `session.accessToken`。
  - `lib/ui/pages/sign_in_page.dart`：Hub 码兑换 + Emby/Jellyfin 手动账密。
  - `AppServices.isSignedIn == janus.isAuthenticated` —— **这是媒体服务器登录，不是自有账号**。
- 更新：`lib/services/updater/updater.dart`（`GET /api/releases/latest` → 下载 → sha256 校验 → 静默安装）+ `lib/ui/widgets/update_dialog.dart`。
- 配置注入：`lib/app/release.dart` 的 dart-define：`AUSHD_DIST_URL`（分发）、`AUSHD_HUB_URL`（枢纽）、`AUSHD_CHANNEL`；`isUsableUrl()` 会拒绝 example.com/localhost。
-  catalog：`lib/data/catalog_api.dart` 全部围绕 Emby `CatalogApi(janus)`；`MediaSource`/`MediaStream` 模型在 `lib/core/emby/models/media_source.dart`。**没有 VFS 抽象**，挂载需要新造。

### 1.2 后端（`server/`）

- 技术栈：**Node.js ≥18，零第三方依赖**，原生 `http` + `fs`，JSON 文件持久化在 `server/data/`。
- 入口 `server/src/server.js`（455 行），路由为 `p === '/xxx'` 的顺序判断（:223 起），无框架。
- 存储 `server/src/store.js`（导出 `Store`），数据文件 `data/releases.json`、`data/codes.json`。
- 现有 API：`/healthz`、`/api/releases`、`/api/releases/latest`、`/download/:file`（Range）、`/api/admin/releases`、`/api/admin/codes`、`/api/app/link`、`/api/app/logs`、`/api/admin/logs`。
- 鉴权：管理接口用 `ADMIN_TOKEN` 常量时间比较；`/api/app/link`、`/api/app/logs` 有基础限流。
- 配置：`.env`（PORT / ADMIN_TOKEN / PUBLIC_BASE_URL / DATA_DIR / ARTIFACTS_DIR / MAX_BODY_BYTES / DIST_URL），Docker + docker-compose 已就绪。
- 测试：`server/test/smoke.js`（18 项端到端）、`scripts/check-deploy.js`（6 项部署自检）。

### 1.3 关键约束（沿用历史经验）

- 本机无 flutter/dart，**所有验证靠 GitHub Actions**（build.yml）；后端改变靠 `cd server && npm test`。
- 中文文件一律用 write/edit（UTF-8），禁用 PS 5.1 `Set-Content`。
- CI 中 build-only 模式 `AUSHD_DIST_URL`/`AUSHD_HUB_URL` 为空，updater/hub 静默禁用——**新功能必须能在无后端配置时优雅降级**。

## 2. 总体架构

```
Flutter 客户端                        server/（现有分发服务，Node 零依赖）
┌──────────────────────┐              ┌──────────────────────────────────┐
│ ConfigService        │ GET /api/config ──────────▶ 配置热更（签名 JSON）
│ AccountApi/AuthSvc   │ /api/auth/*  ──────────▶ 自有账号 + token
│ SyncService          │ /api/sync    ──────────▶ 设置/片单/偏好同步
│ DanmakuProvider      │ /api/danmaku/<key>（V2，V1 留空/本地源）
└──────────────────────┘              └──────────────────────────────────┘
         │
         │ 直连（不经本后端）
         ▼
   OpenList 实例（用户自建）：WebDAV / SMB / 各家网盘 → 统一 HTTP API → 直链喂 mpv
```

**账号正交原则**：AusHD 自有账号（管云同步/配置/弹幕身份）与 Emby/Jellyfin 媒体登录（管媒体库访问）**并存、可关联、不合并**。绝不把 `janus.isAuthenticated` 与自有账号登录状态混为一谈。

## 3. 后端扩展设计（`server/`）

### 3.1 路由扩展点

在 `server/src/server.js` 的顺序判断链中新增（保持零依赖风格）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/config` | 热更配置，按 platform/channel/tag 返回，签名 |
| POST | `/api/admin/config` | 写配置（Bearer ADMIN_TOKEN） |
| POST | `/api/auth/register` | 注册（用户名/邮箱 + 密码 hash） |
| POST | `/api/auth/login` | 登录，返回 access + refresh token |
| POST | `/api/auth/refresh` | 刷新 token |
| POST | `/api/auth/device-code` | TV 设备码（生成待确认码） |
| POST | `/api/auth/device-token` | TV 轮询换 token |
| GET | `/api/sync` | 拉取同步数据（Bearer） |
| PUT | `/api/sync` | 推送同步数据（Bearer，按 updatedAt 合并） |
| GET | `/api/danmaku/<mediaKey>` | 共享弹幕（V2，V1 可返回 404） |

### 3.2 存储扩展

`server/data/` 新增：`config.json`、`accounts.json`、`sync/<userId>.json`、`deviceCodes.json`。
沿用 `Store` 模式（读文件 → 改 → 写回，注意并发串行化）。密码用 `node:crypto` 的 `scryptSync` + 随机 salt，token 用随机字节 + 签名，**绝不存明文**。

### 3.3 配置签名

配置响应带 `signature`（HMAC-SHA256，密钥由服务端私钥/ADMIN_TOKEN 派生），客户端用内置公钥或共享密钥校验。无后端配置时客户端用本地默认，静默跳过。

### 3.4 安全

- 管理接口沿用 `ADMIN_TOKEN` 常量时间比较。
- 账号接口加限流（按 IP）、密码最小长度、失败次数限制。
- token 短期 access + 长期 refresh，refresh 可撤销。
- 同步数据含用户偏好，按隐私数据保管，设置保留期。
- 所有新接口在 `npm test`（smoke.js）补端到端用例，`check-deploy.js` 补部署自检。

## 4. 客户端扩展设计

新增模块（目录）：

```
lib/services/config_remote/   remote_config.dart, config_service.dart
lib/data/account/             account.dart, account_api.dart, auth_service.dart

```

### 4.1 配置热更（阶段 1）

- `ConfigService`：`GET /api/config?platform=&channel=&tag=`，签名校验、TTL 缓存（SharedPreferences）、失败回退本地默认。
- `RemoteConfig` 模型：`version` + `homeRows`(行 id 顺序/显隐覆盖) + `featureFlags` + `announcements` + `danmakuSources` + `openlistPresets`。
- 接入：`AppServices.create()` 加载；`home_page._buildRows` 读行覆盖；shell 读 featureFlags。
- 单测：解析/合并/签名/回退（纯 Dart）。

### 4.2 弹幕（阶段 3，依赖阶段 1 下发源列表）

- `Danmaku`：`timeMs / text / color / mode(scroll|top|bottom) / fontSize`。
- `DanmakuProvider` 抽象：`Future<List<Danmaku>> fetch(String mediaKey)`；内置 `LocalDanmakuProvider`（本地 .xml/.ass）与（V2）`RemoteDanmakuProvider`。
- `danmaku_ass.dart`：弹幕 → ASS `[Script Info]`+`[V4+ Styles]`+`[Events] Dialogue` → 临时 `.ass` → mpv `sub-add <path> select`；开关/字号/透明度/类型屏蔽。
- 接入：播放启动时（`playback_session`/`mpv_backend`）按媒体 id 注入。
- 单测：ASS 生成、provider 解析；**注入时机/字体回退需真机调**。

### 4.3 自有账号 + 云同步（阶段 4）

- `AccountApi`（HTTP）、`AuthService`（token 存取/刷新，存 SharedPreferences/BlobStore、**不入库**）、`Account` model。
- UI：扩展 `sign_in_page` 加"AusHD 账号"页签（账密 + 设备码）；`profile_page` 显示账号与同步开关。
- 同步内容：`AppSettings`、片单（`ProfileService.list`）、偏好（`taste_profile`）；冲突策略按 `updatedAt` + 用户手选。
- 接入 `AppServices` 新增 account/sync 字段；`isSignedIn` 保持指向 janus，新增 `isCloudSignedIn`。

### 4.4 协议挂载 + OpenList（阶段 2）

- `VirtualFileSystem` 抽象：`list(path)` / `resolvePlayableUrl(path)` / `stream(path)`。
- `OpenListVfs`：对接 OpenList REST API（`GET /d` 列目录、直链），直链直接喂 mpv（复用现有 direct-play 链路）。
- `WebDavVfs`：`PROPFIND` 列目录（不用 OpenList 时的补充通道）。**SMB 不直连**（Dart 无成熟库，原生桥接成本高），统一交给 OpenList。
- UI：设置页"存储源"管理（地址/token）；`storage_browser_page.dart` 网盘文件浏览 + 播放；媒体库加入口。
- 元数据增强（可选）：网盘文件按文件名匹配 `TmdbApi` 补全海报/评分。
- 单测：路径规范化、直链拼接、目录解析；**真 OpenList 由用户验收**。

## 5. 后端 API 契约（客户端按此编码）

### 5.1 配置

```
GET /api/config?platform=windows&channel=stable&tag=v1.0.9
→ 200 {
  "version": 7,
  "homeRows": ["continueWatching","trending","popularShows",...],  // 行 id 顺序；未知 id 忽略
  "featureFlags": {"danmaku": true, "openlist": true, "cloudSync": false},
  "announcements": [{"id":"a1","text":"...","url":"..."}],
  "danmakuSources": [],           // V1 空
  "openlistPresets": [],          // 可选预置公共实例
  "signature": "<HMAC-SHA256 over canonical JSON>"   // 无签名则客户端拒绝应用
}
→ 204/404 无更新；其他非 200 客户端静默回退
```

### 5.2 账号

```
POST /api/auth/register  {username,email,password} → 201 {userId}
POST /api/auth/login     {username,password}       → 200 {accessToken,refreshToken,expiresIn}
POST /api/auth/refresh   {refreshToken}            → 200 {accessToken,expiresIn}
POST /api/auth/device-code   {}                     → 200 {code,verifyUrl,expiresIn}   // TV 显示码 + 二维码
POST /api/auth/device-token  {code}                 → 200 {accessToken,...} / 202 pending / 410 expired
```

### 5.3 同步

```
GET /api/sync   (Bearer) → 200 {
  "updatedAt": "ISO8601",
  "settings": {...}, "list": [...], "taste": {...}
}
PUT /api/sync   (Bearer) {updatedAt, settings?, list?, taste?}
→ 200 {updatedAt, applied:[...]}   // 服务端按字段 updatedAt 合并，冲突返回 409 {server, hint}
```

### 5.4 弹幕（V2）

```
GET /api/danmaku/<mediaKey>?format=json → 200 {items:[{timeMs,text,color,mode,size}]}
```

### 5.5 OpenList（外部实例，非本后端）

```
GET  <openlist>/d/<path>        (Header: Authorization) → 目录项 JSON
GET  <openlist>/d/<path>?sign=...  → 文件直链（喂 mpv）
```

## 7. 诚实边界

- 本机无 flutter，CI 只验证编译/单测/构建；**后端接口、OpenList 直链、mpv 弹幕注入的真机效果需用户验收**。
- 后端由我们扩展 `server/`，但**部署环境/域名/HTTPS 反代由用户负责**（客户端会拒绝 example.com/localhost）。
- SMB 不做客户端直连，统一由 OpenList 暴露；用户需自建 OpenList 实例。
- 无后端配置（build-only CI、离线自构建）时，四块功能全部优雅降级：配置用本地默认、账号入口隐藏、弹幕/网盘入口隐藏。
- 账号与媒体登录正交，用户可能有"没登自有账号但能看库"的状态，UI 需清晰区分。

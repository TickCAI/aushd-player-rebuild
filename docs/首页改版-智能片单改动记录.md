# 首页改版 · 智能片单改动记录

## 0. 一句话结论

把首页从「一次铺 ~30 行、推荐算法反复 churn」改成「六区 ≤12 行、六条声明式智能片单按评分/口味/新鲜度排序、低于阈值整行隐藏」，并给每条片单加「更多」入口打开同规则的全网格浏览页。数据层与 UI 解耦，评分/去重/缓存都是可单测的纯 Dart 函数。

## 1. 做了什么

### 1.1 数据层（`lib/data/smart_list.dart`，新增）

- `SmartSpec`：声明式片单定义（类型/排序/过滤/评分区间/年份/时间窗/最少条数/上限/是否打分/是否依赖 Seerr）。
- 六条首页片单 + 一条「更多」用片单：
  | id | 含义 | 来源 | 关键规则 |
  |----|------|------|----------|
  | `this-week` | 本周更新 | Emby | 7 天内入库的剧集/剧集，按日期倒序 |
  | `one-ep` | 一集入坑 | nextUp | 按 seriesId 去重，每剧一集 |
  | `classics` | 高分经典 | Emby | 评分≥8、2015 年前、未看，打分排序 |
  | `fresh` | 新片速递 | Emby | 90 天内首播，按首播倒序 |
  | `gems` | 冷门佳作 | Emby | 评分 6.5–7.8、未看，打分排序 |
  | `picks` | 本周推荐 | Emby | 评分≥7、未看、口味 genre 命中，打分排序 |
  | `my-list` | 我的片单（更多页用） | local | 占位，我的清单仍走 profile |
- 打分：`score = 0.45*norm(rating) + 0.30*tasteMatch + 0.15*freshness + 0.10*stableJitter`。jitter 用 FNV-1a 对 id 取哈希，保证同一条目每次刷新顺序稳定，不会「刷一下全变」。
- `SmartListResolver`：把 spec 变成片单。服务端 query + 本地兜底过滤（评分上界、年份上限、时间窗、未看）→ 打分排序 → 按 id 去重 → 取上限。**低于 minItems 整行隐藏**（不显示空行）。
- 缓存：30 分钟 TTL 内存 Map，按 `spec.id|口味genre` 分键；库变化/手动刷新时 `invalidate()`。

### 1.2 首页（`lib/ui/pages/home_page.dart`）

- `_buildRows` 从 ~30 行重写为六区 ≤12 行、标题无重复：
  - A 续看：continueWatching
  - D 分类：myLibraries（已与继续观看同尺寸对齐，见 M1 记录）
  - B 更新：本周更新、一集入坑
  - C 榜单：高分经典、新片速递、冷门佳作、热门趋势（仅 Seerr 已配置时）
  - E 片单：我的片单、我的收藏
  - F 推荐：本周推荐、为你推荐（算法 outlet 沉底）
- 每条智能行带 `SmartSpec`；行尾「更多」按钮（`trailingTitle`）在传入 `onOpenSmartList` 时显示。
- `refresh()` 里 `SmartListResolver.invalidate()`，手动/库刷新丢弃缓存。
- 智能行 `recommends:false`：这些片单已自带口味/未看过滤，全局 `keptInRecommendations` 闸会误杀。

### 1.3 「更多」目标页（`lib/ui/pages/smart_list_page.dart`，新增）

- `SmartListPage(spec)` 用**同一个 spec 和 resolver** 解析（首页行与网格永不两家话），渲染海报网格，复用 MyListPage 的网格布局与卡片。
- 库变化时重新解析；空态用 `myListEmpty`。
- `routes.dart` 加 `openSmartList(context, spec)`；`shell.dart` 把 `onOpenSmartList` 接到 HomePage。

### 1.4 国际化

`app_en.arb` / `app_zh.arb` 各加 7 个 key：smartThisWeek / smartClassics / smartFresh / smartGems / smartOneEp / smartPicks / smartMore。

### 1.5 单测（`test/smart_list_test.dart`，新增）

- 打分原语：评分归一化/夹取、jitter 确定性与范围、新鲜度三年半衰期、口味命中、加权和。
- 片单规则：id 去重、打分排序、本地兜底过滤（评分上界/年份/未看）、时间窗、低于 minItems 隐藏。
- 片单目录：六条 id 唯一且可反查、limit≥minItems。

## 3. 诚实边界

- 托管 runner 无 AMD GPU，也不连真实 Emby 服务器：云端验证的是**编译 + 单测 + 窗口层无回归**，不是片单在真实媒体库上的排序效果。
- 打分权重/时间窗/最少条数是方案里的初值，真实口味匹配度需要真机观察后微调。
- 「更多」网格页在空库/单条超少时的观感，只有当用户在真机点开才知道。

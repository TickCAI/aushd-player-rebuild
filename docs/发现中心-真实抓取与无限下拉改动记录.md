# 发现中心：真实抓取 + 海报信息 + 无限下拉（2026-11-22）

## 0. 一句话结论

按用户最初设计图把「发现内容」和「已拥有内容」拆成两套体系：智能片单**退回纯本地媒体库**，新增独立的**发现中心**页，用 TMDB/Seerr **真实分页抓取** 7 个分类，海报统一走"请求"样式（永远不映射成本地可播放条目），往下滑动时**逐页无限加载**。

## 1. 为什么要转向

v2 把 TMDB/Seerr 的补位结果混进了本地智能片单（`resolveMixed`），发现到的片子和已拥有的片子并排显示——这违背了原设计「发现中心的海报只是信息、不代表已拥有、不能直接播放」的核心原则。所以：

| 问题 | v2 做法（已废弃） | 本次做法 |
| --- | --- | --- |
| 发现 vs 拥有 | `resolveMixed` 把 SeerrMedia 补进本地片单，视觉混排 | 两套体系彻底分离：智能片单只读本地库；发现内容只在发现中心 |
| 片源 | 智能片单按阈值切本地库 | 发现中心真实调用 TMDB/Seerr，7 个不同意图的分类 |
| 分页 | 一次性 Future，固定行数 | ScrollController 触底 `loadMore()`，逐页抓取、按 key 去重、无限下拉 |

## 2. 智能片单退回纯本地

- `home_page.dart` 删除 `_smartTopUp()` 与 `resolveMixed()` 调用；`_smartRow()` 改为 `SmartListResolver(catalog, taste).resolve(spec)`——只返回本地 `EmbyItem`。
- `smart_list.dart` 的 `SmartTopUp/resolveMixed` 保留（v2 已有、单测覆盖），但首页不再接线。

## 3. 数据源 `lib/data/discovery_feed.dart`（新）

- `DiscoverySource({tmdb, seerr, language})`：`available = tmdb != null || seerr != null`；`fetch(category, page)` 真实抓取**一页**。
  - 优先用 TMDB（配了 API key），否则退回 Seerr；两者都没有则不抓。
  - `mediaStatuses()` 补 availability，让卡片显示"请求 / 已请求 / 已有 / 即将上映"状态；状态查询失败只记 log、不 blank 掉整页。
- 7 个分类各自是**不同的真实查询**：

| 分类 | 数据源 | 查询 |
| --- | --- | --- |
| 今日精选 | TMDB trending day / Seerr trending day | 当日热门 |
| 正在热映 | TMDB discover movie + `with_release_type=2\|3` | 影院/新片 |
| 即将上映 | TMDB `/movie/upcoming` / Seerr upcoming | 预告新片 |
| 本周热门 | TMDB trending week / Seerr trending week | 一周热门 |
| 高分佳作 | TMDB discover movie `vote_average.desc` + `vote_count>=3000` | 高分 |
| 热门剧集 | TMDB discover tv `popularity.desc` | 热门剧 |
| 动漫精选 | TMDB discover movie `with_genres=16` | 动画 |

- `DiscoveryFeed`：`loadMore()` 每次抓下一页，按 `SeerrMedia.key`（`type:tmdbId`）去重追加；电影与剧集同 tmdbId 视为不同条目；新增数为 0 或到达 500 页上限时停；异常只结束本次会话（下拉刷新可重试）；并发调用被忽略。`reset()` 供刷新使用。

## 4. 发现中心页 `lib/ui/pages/discover_page.dart`（重写）

- 顶部标题 + 7 个分类 chip（横向可滚），选中态用 request 高亮。
- 海报网格复用 `my_list_page` 的布局（列数随设置、固定宽高比）；每张卡是 `RequestPosterCard`（NetImage 海报 + 状态 pill + 标题/年份），点击 `openRequest()` 进请求页——**不 resolve 成本地 EmbyItem、不提供播放**。
- 无限下拉：`RevealController` 触底（距底 600px）触发 `loadMore()`；网格末尾始终有"加载更多"格（loading 时骨架、到底时"已经到底啦"）；`maxScrollExtent<=0` 时跳过，避免首屏未撑满时空转。
- 没配 Seerr/TMDB 时显示引导文案，Discover tab 的显示门槛也从「必须 Seerr」放宽到「Seerr 或 TMDB」。
- 首页新增一个视觉分离的「发现」入口卡（独立边框/配色/图标），点击切到 Discover tab。

## 6. 诚实边界

- 云端 runner 不连真实 TMDB/Seerr，所以"真实抓取是否返回预期内容""海报是否都能加载"无法在云端证明，需真机配好 API key 验证。
- 只配 TMDB（没配 Seerr）时，卡片状态 pill 不显示 Seerr 请求状态（无 `mediaStatuses` 来源），但海报/标题/评分照常显示、点击仍进请求页（请求页会提示需要 Seerr）。
- Seerr-only 且无 `with_genres` 支持时，「动漫精选/正在热映」降级为 Seerr popular feed。
